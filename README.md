# Express Entry CRS Widget

A Scriptable iOS widget that tracks your Canada Express Entry CRS score and the latest draw cut-offs — generated by an AI interview, no coding needed.

## What it does

- Estimates your CRS score.
- Suggests hypothetical ways to improve it.
- Shows recent IRCC draw cut-offs.

The included profile is fictional. A cut-off comparison does not establish eligibility or guarantee an invitation. Tie-breaking rules also apply.

## Two ways to use it

### A. AI route

1. Copy [the interview prompt](prompt/crs-widget-prompt.md) into ChatGPT, Claude, or Gemini.
2. Attach [the CRS tables](data/crs-tables.json) and [the reference script](script/crs-widget.js). Alternatively, provide accessible raw file URLs. A repository link or relative path alone may not be readable by the AI.
3. Optionally attach a design screenshot. Answer the questions and confirm your profile.
4. Paste the generated script into Scriptable.
5. Check the estimate and its assumptions against current official IRCC information.

**How the AI uses the files**

- The JSON tables are the first source for calculations. The reference script's calculation logic is a limited fallback.
- The reference script assumes no accompanying spouse and uses CELPIP. It does not cover every profile or CRS factor.
- If the JSON is unavailable or incomplete, the AI must identify factors the script cannot handle as unknown or uncertain. It must not assume zero or present an incomplete estimate as a complete score.
- A generated widget can use an accessible raw JSON URL with an embedded offline fallback. Without a URL, it must rely on embedded data.

### B. Direct route

1. Copy [the reference script](script/crs-widget.js) into Scriptable.
2. Edit the `MY` profile in the code. See [setup](docs/setup.md).

The reference script uses its own limited scoring logic. It does not load the CRS tables JSON or provide an in-app profile editor.

The direct route is a reference version with three fixed improvement scenarios: a language target, one more year of Canadian work, and a provincial or territorial nomination. For improvement scenarios tailored to your profile, use the AI route.

The reference script needs an internet connection to fetch IRCC draw results; if the request fails, it shows an error instead of previously fetched results.
